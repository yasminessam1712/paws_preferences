# Paws Preferences

Paws Preferences is a Flutter application that helps users explore and manage 
their pet preferences in a simple and interactive way.  

## Features

- Browse different categories of pets and accessories
- Select your favorite items
- Responsive Flutter UI for mobile and web
- Clean and structured Flutter project
